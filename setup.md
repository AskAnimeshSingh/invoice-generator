# Setup

## Requirements

- Node.js 18+
- npm

## Install (once)

```bash
npm run install:all
```

## Run

```bash
npm start
```

App → http://localhost:5173

PDF is generated in the browser (no separate API server needed).

## Deploy (Vercel)

1. Push to GitHub
2. Import repo in Vercel (Root Directory = empty / `.`)
3. Deploy
